# Code

- `part1/`: sechs Kursaufgaben, nach Aufgabe geordnet.
- [part2/](part2/README.md): Milch-miRNAs und PFKL-Modell.
- [text_mining/](text_mining/README.md): regelbasierte Literaturauswertung.
- `tools/`: Quellenexport, Buchressourcen und historische Pfadzuordnungen.

Befehle gelten ab Projektwurzel, sofern nicht anders angegeben. Daten und Dokumentquellen liegen nur in der vollständigen lokalen Projektablage.

Historische Skripte dort mit `python3 code/tools/run.py <skript>` ausführen. Der Starter stellt ihre alten Pfade in einer Kopie wieder her; Ergebnisse landen unter `output/runs/`. `--layout <datei>` wählt eine andere Pfadzuordnung.
