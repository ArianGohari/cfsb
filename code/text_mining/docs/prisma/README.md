# PRISMA-Unterlagen zu Aufgabe 1(g)

Die Unterlagen dokumentieren die frühere Planung der Literaturauswertung. Sie sind kein Nachweis einer abgeschlossenen Review oder erfüllten PRISMA-Checkliste.

- [Protokoll](protocol.md): Frage, Suchrahmen, Kriterien und offene Entscheidungen.
- [Tracking](tracking.md): Treffer, Auswahlentscheidungen und Zählregeln.
- [Aktuelle Pipeline](../../README.md): regelbasierte Umsetzung.

PRISMA beschreibt die Berichterstattung, nicht die Qualität einzelner Studien. Suchstrategie, Datenquellen, Abrufdaten, Limits, Deduplikation und Ausschlussgründe müssen nachvollziehbar bleiben. Records, Reports und Studies werden getrennt gezählt. Ein Flussdiagramm oder Knowledge Graph ersetzt weder Biasbewertung noch fachliche Prüfung.
