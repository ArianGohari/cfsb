# Computational (Food) Systems Biology

Kursprojekt von Arian Gohari, Ludwig-Maximilians-Universität München.

| Code | Inhalt |
|---|---|
| [Teil I](code/part1/) | Sechs Aufgaben zu Modellen, Parameterschätzung, SBML und Netzwerkanalysen |
| [Teil II](code/part2/README.md) | Milch-miRNA-Recherche und bedingte miR-6517/PFKL-Simulation |
| [Text-Mining](code/text_mining/README.md) | Regelbasierte Literaturauswertung für Teil I |
| [Hilfsskripte](code/tools/) | Quellenexport, Quarto-Ressourcen und Pfadzuordnungen |

Auf GitHub liegen nur Code, technische Dokumentation und Umgebungsdateien. Report, Präsentation und Teil-I-Buch werden separat abgegeben.

Der vollständige [Reproduktionsablauf](code/part2/reproduction/README.md) benötigt zusätzliche lokale Daten und Dokumentquellen. Eine Git-Kopie allein reicht dafür nicht. Lokal bleiben `report/`, `presentation/`, `code/`, `data/`, `output/`, `archive/` und `obsidian/` getrennt.
