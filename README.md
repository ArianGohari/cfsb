# CFSB-Projekt

Dieses Repository enthält die reproduzierbare Ausarbeitung für das Projekt in
Computational (Food) Systems Biology. Der aktuelle Stand von Teil I liegt unter
[`part1/`](part1/README.md); die maßgebliche Aufgabenstellung ist
[`project.md`](project.md).

Das Quarto-Buch wird so erzeugt:

```sh
cd part1
quarto render
```

Die Kapitel dokumentieren ihre jeweiligen Prüf- und Reproduktionsbefehle.
Lokale Paper-PDFs und deren Volltextkonvertierungen, große Rohkorpora,
virtuelle Umgebungen und Build-Ausgaben sind nicht Teil des Git-Repositories.
Verwendete Quellen werden in den Auditdateien durch Herkunft, Version oder
Commit und Prüfsummen festgehalten.

Der fortlaufende Arbeitsstand und die bekannten Grenzen stehen in
[`UEBERGABE_2026-09-22.md`](UEBERGABE_2026-09-22.md).
